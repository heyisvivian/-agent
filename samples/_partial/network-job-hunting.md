🇫🇷 非传统 network 找到工作的真实案例
我说的是我认识的一个澳洲女生，我会分享一下她的故事，但是不是都适用。

在法国，大家经常说 network 对于找工作有多重要，多轻松，比正常投递要快很多。说实话这个理论对找实习的我来说是 bullshit，因为我没有任何的资源，而凭借在一些论坛会上或者 viva tech 之类和公司宣讲人聊几句就让别人给你 referal 简直就是天方夜谭，而且我讨厌这个社会行为。

后来我慢慢进入职场，我发现我可能错了，首先我们自己的部门，有一个男生是因为和我老板以前一起工作过所以被带过来。另一个男生也是因为一次 soiree 而进入这个公司，之前他是 0 经验。有个女生是通过 referal，而我是投递简历进来的，这个时候我依旧不觉得能够打破我对 network 的 bullshit 看法。

直到这个澳洲女生的出现，首先她每天 10 点左右到公司，下午 3.4 点就下班了，我刚开始就好奇，就算是实习也不是这样的吧？后来和她熟悉了之后，才知道她竟然是公司的 CEO 小孩的住家保姆！？ WTHF，我当时真的是震惊了，而且她后面会转 CDD，后来我就更加详细的问了，她说她已经和 CEO 工作了一年然后就被推荐这个公司了。她是我们公司第二个讲英语的人，我是第一个，突然觉得我给她的存在也创造了空间哈哈。Anyway 回归正题，她真的颠覆了我对法国的 network 的看法…
