# samples/ —— 你的历史笔记

这里放你**已经发过**的小红书笔记，用来学你的语气。

⚠️ **这个目录已 gitignore，不会上传到 GitHub。**（只有本文件和 `example.md` 会）

---

## ★ 按内容类型分子目录

这个账号有两种内容，写法不是同一套，所以**分开放、分开统计**：

```
samples/
├── guide/     科普 / 信息型（法规解读、清单、干货）
└── life/      生活 / 日常 / vlog / 旅行
```

```bash
python skills/xhs-voice/scripts/voice_stats.py samples/guide
python skills/xhs-voice/scripts/voice_stats.py samples/life
```

**混在一起统计没意义** —— 两种模式的 emoji 密度会被平均成一个不存在的数字。
科普稿 emoji 当项目符号（每百字 2.7 个），生活稿可能一个都不用，
平均出来 1.3 个，两边都不对。

只有一种内容就直接放 `samples/` 根目录。
第三种类型（比如恰饭稿、测评）就再开一个子目录。

## 怎么放

一篇一个文件，`.md` 或 `.txt` 都行。文件名随便。

推荐格式（带 frontmatter，统计脚本能识别标题）：

```markdown
---
title: 京都下雨那天我什么都没干
---
最近总在想，旅行是不是一定要把行程填满。

第一次去京都我做了很详细的攻略，早上六点起，一天跑五个地方。这次我什么都没安排。

……
```

**懒得加 frontmatter 也行** —— 直接粘贴正文，第一行会被当成标题。

参考 `example.md`。

## 怎么导出

小红书没有批量导出。都得手动，几种方式：

1. **App 里复制** —— 我的 → 笔记 → 打开 → 长按正文复制 → 粘贴进新文件
2. **创作者后台** —— 电脑上打开 creator.xiaohongshu.com，笔记管理里复制
3. **你本来的草稿** —— 如果你在备忘录/Notion 里写过草稿，直接拿过来

**不要用爬虫。** 平台反爬 + 违反 ToS，而且没必要 —— 手动贴 15 篇也就十几分钟。

## 放几篇

| 篇数 | 效果 |
|---|---|
| **15+** | 统计稳定，档案能做得很准 ★ |
| 8–14 | 够用，少数特征会不稳 |
| 3–7 | 只能抓大方向，档案会标「样本不足」 |
| 0 | 走问卷冷启动（`skills/xhs-voice/references/questionnaire.md`） |

---

## 挑哪些篇

**挑你自己满意的**，而不是数据最好的。

写得不像你的那几篇（比如硬着头皮写的恰饭稿、照模板套的攻略）会**污染档案** ——
学出来的语气会往那个方向偏。

如果某几篇你自己都觉得「这不像我写的」，别放进来。

有恰饭稿的话可以单独放，但**文件名里标一下**（比如 `ad-xxx.md`），
这样档案里能区分「日常语气」和「恰饭语气」。
