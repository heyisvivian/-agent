# samples/ —— 你亲手写的笔记

这里放你**自己写的**小红书笔记，用来学你的语气。

⚠️ **这个目录已 gitignore，不会上传到 GitHub。**（只有本文件和 `example.md` 会）

---

## 🛑 只放你自己写的

**AI 生成或 AI 起草的稿子不要放进来。**

拿 AI 稿学"你的语气"，学到的是那个 AI 的语气。然后它写出来的更像通稿，
你又把这些稿子当语料喂回来 —— **几轮之后你的账号就是纯 AI 味，
而且是自己一步步喂出来的。**

放进来之前问一句：**这篇的句子是我自己敲的吗？**

| 情况 | 放不放 |
|---|---|
| 从头到尾自己写的 | ✅ 放 |
| 自己写完自己改的 | ✅ 放 |
| AI 起草 + 你大改（面目全非） | ⚠️ 可以，但文件名标一下 `ai-draft-xxx.md` |
| AI 起草 + 你小改（顺一顺） | ❌ 别放 |
| 全部 AI 生成 | ❌ 别放 |

AI 稿想留着参考就放 `samples/_ai/` —— 下划线开头，统计脚本不会去读那个目录。

### 如果某类内容你一向是 AI 起草

那这类内容的档案换个做法：**不是"提取你的语气"，是"定义你希望它读起来什么样"。**
跟 agent 说清楚你的实际工作方式，它会改用问答的方式建这一节
（问你改 AI 稿时最常删什么、哪种句子看到就想改）。

## ★ 按内容类型分子目录

这个账号有两种内容，写法不是同一套，所以**分开放、分开统计**：

```
samples/
├── guide/     科普 / 信息型（法规解读、清单、干货）
└── life/      生活 / 日常 / vlog / 旅行
```

```bash
python skills/xhs-voice/scripts/voice_stats.py samples/guide
python skills/xhs-voice/scripts/voice_stats.py samples/life
```

**混在一起统计没意义** —— 两种模式的 emoji 密度会被平均成一个不存在的数字。
科普稿 emoji 当项目符号（每百字 2.7 个），生活稿可能一个都不用，
平均出来 1.3 个，两边都不对。

只有一种内容就直接放 `samples/` 根目录。
第三种类型（比如恰饭稿、测评）就再开一个子目录。

## 怎么放

一篇一个文件，`.md` 或 `.txt` 都行。文件名随便。

推荐格式（带 frontmatter，统计脚本能识别标题）：

```markdown
---
title: 京都下雨那天我什么都没干
---
最近总在想，旅行是不是一定要把行程填满。

第一次去京都我做了很详细的攻略，早上六点起，一天跑五个地方。这次我什么都没安排。

……
```

**懒得加 frontmatter 也行** —— 直接粘贴正文，第一行会被当成标题。

格式参考 `_format-example.md`。

⚠️ 那个文件名以**下划线开头**是故意的 —— 下划线开头的文件和目录
`voice_stats.py` 一律跳过，所以它不会被当成你的语气样本。
你自己的笔记用正常文件名（不带下划线）。

## 怎么导出

小红书没有批量导出。都得手动，几种方式：

1. **App 里复制** —— 我的 → 笔记 → 打开 → 长按正文复制 → 粘贴进新文件
2. **创作者后台** —— 电脑上打开 creator.xiaohongshu.com，笔记管理里复制
3. **你本来的草稿** —— 如果你在备忘录/Notion 里写过草稿，直接拿过来

**agent 现在可以帮你读**（2026-08 放开，见 `AGENTS.md` 1.5）—— 但只在你登录态下读你自己的，
碰到验证码就停。最稳的还是创作者后台导出；手动贴 15 篇也就十几分钟。

## 放几篇

| 篇数 | 效果 |
|---|---|
| **15+** | 统计稳定，档案能做得很准 ★ |
| 8–14 | 够用，少数特征会不稳 |
| 3–7 | 只能抓大方向，档案会标「样本不足」 |
| 0 | 走问卷冷启动（`skills/xhs-voice/references/questionnaire.md`） |

## 挑哪些篇

**第一道筛：是不是你自己写的。**（见上面那节，这条不能让）

**第二道筛：挑你自己满意的**，而不是数据最好的。

写得不像你的那几篇（比如硬着头皮写的恰饭稿、照模板套的攻略）会**污染档案** ——
学出来的语气会往那个方向偏。

如果某几篇你自己都觉得「这不像我写的」，别放进来。

有恰饭稿的话可以单独放，但**文件名里标一下**（比如 `ad-xxx.md`），
这样档案里能区分「日常语气」和「恰饭语气」。
