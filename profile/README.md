## account.md —— 数据基线（第一优先）

指标口径 · 每篇互动台账 · 效率表 v2（按引擎：收藏 / 评论 / 分享 / 引流）·
护城河排序 · 选题库 · 回流节奏。

它是 `xhs-strategy` 的输入（**缺它不给方向建议**），也是发布后数据的回写处：
每发一篇 D+7 回填四项互动（赞/藏/评/享），每月或每 10 篇重算效率表。
它停更，选题就回到拍脑袋。

## voice.md

这是①数据基线的**语气半边**（数据半边、也是第一优先的，是 account.md ——
2026-08-20 起选题 > 笔锋）。`xhs-note`（写）和 `xhs-polish`（改）
每次开工前都会读它。

**没有它，写出来的一定是 AI 通稿腔** —— 模型对「小红书博主」的默认印象是
`✨氛围感拉满✨`、`姐妹们冲`、`值得一提的是`。档案的主要作用是**把这个默认关掉**。

### ★ 档案是分模式的

这个账号有三种内容 —— **种草、攻略、生活** —— 写法不是同一套。
攻略稿里 emoji 当评分刻度（💣🌟）是对的，种草稿里连排同款就成模板号了；
种草内部还分 A1 罗列型（零标点、空格断句）和 A2 叙事型（全标点）。

所以 `voice.md` 分成：模式 A（种草，内分 A1/A2）、模式 B（攻略）、
模式 C（生活）、共同底线。
写稿之前**先定模式**。

出现第三种内容（恰饭稿、测评）就再加一个模式，不要硬塞进现有的。

### 怎么生成

1. 把你发过的笔记放进 `samples/`，**按类型分子目录**（`samples/guide/`、`samples/life/`）
2. 跟 agent 说「学一下我的语气」
3. 生成 `profile/voice.md`，然后**验收一下**（它会问你几个具体问题）

没有历史笔记就走问卷冷启动：`skills/xhs-voice/references/questionnaire.md`。

看 `voice.example.md` 了解档案长什么样 —— 那份的科普模式是从一篇真实笔记提的，
生活模式**故意留空**，因为还没有样本。

> **样本不足时留空比填满更有价值。** 一份标着「生活模式：无样本，以下 9 个问题
> 答不了」的档案是诚实可用的；凭空编满会让每篇生活稿都错，而且错得很自信。

## voice.md 进 git（2026-08-21 改的）

以前它是 gitignore 的，理由是**这个仓库是公开的**
（github.com/heyisvivian/xiaohongshu-agent），而档案里有你笔记的原文引用和
写作习惯分析。

2026-08-21 你决定放进来。成立的前提是：档案引用的原文都是你**已经发布过**的笔记，
本来就公开。换来的是多机同步、版本追溯，以及每条结论都能被复核 ——
档案里每一条都标了原文出处和样本篇数，这些只有语料也在 git 里才对得上。

⚠️ **由此要守的一条**：档案里不要写你没公开过的东西 ——
未发布的选题、私人的事、别人的信息。要记这类内容就往本地另开一个文件，别放这里。

## 档案要维护

你的风格会变。

- **每积累 10 篇新笔记** → 放进 `samples/` 重跑 `xhs-voice`，看统计有没有漂移
- **你说「这个不像我」的时候** → 不要只让 agent 改那一篇，
  要把结论写回档案。**一次这样的反馈价值大于十篇样本。**
- 开始接商业合作后 → 恰饭稿的语气可能和日常不一样，在档案里单独开一节

---

## 档案里最有用的部分

是**「绝对不是她」那个反例清单**，不是「她是什么」。

「她克制、真诚、有细节」——这种描述模型没法执行。
「不用感叹号、不用『姐妹们』、结尾不升华」——这个能执行。

所以写档案和维护档案时，多往反例清单里加东西。
