# 发布前检查清单（模板）

复制到 `drafts/<日期>-<slug>/checklist.md`，逐项确认。
**不要替用户打勾。**

---

## 文字

- [ ] 跑过 `xhs_scan.py`，0 个 L1、0 个 L2
- [ ] `--type` 和内容模式一致（`life` 生活 / `guide` 科普清单 / `short` 一句话）
- [ ] L3 命中逐条看过，该软化的软化了
- [ ] 标题 ≤ 20 字，前 20 字能独立成句
- [ ] 正文 ≤ 1000 字
- [ ] 标签 3–6 个，每个都真的和内容相关
- [ ] 标签**一次选对** —— 发完有流量再改容易限流
- [ ] 没有拼音/谐音/插符号的规避写法
- [ ] 标题承诺的东西，正文第一段就给到了

## 图片 / 视频

- [ ] 封面 3:4，主标题 9–13 字
- [ ] 封面文字没压到安全区外（上下各留 8%，避免被 UI 遮）
- [ ] **没有其他平台水印**（抖音/快手/B站 logo 或 ID）→ 这条判搬运，很确定限流
- [ ] 剪映导出时关掉了片尾
- [ ] 图里没有微信号、二维码、链接
- [ ] 他人正脸征得同意；小孩的脸打码或不用
- [ ] 车牌、门牌号、证件、登机牌、房号都打码了
- [ ] 图片 ≤ 18 张

## 合规声明

- [ ] 正文主要由 AI 起草
      → **发布页【设置】→【内容类型声明】→ 勾选【笔记含 AI 合成内容】**
- [ ] 有任何对价（钱 / 免费 / 置换 / 返现 / 免单 / 免费试住）
      → **走蒲公英报备**
- [ ] 没有对价的话，考虑写一句「自费，无合作」

## 事实核实

- [ ] 价格是最近核实的，并标了时间（「2026年8月我去的时候」）
- [ ] 营业时间 / 休息日核实过
- [ ] 签证、免签政策标了「以官方最新公告为准」
- [ ] 所有「我去了/我吃了/我用了」都是真的发生过

## 发布设置

- [ ] 定位选对（有地点的笔记加定位能吃到本地流量）
- [ ] 选了合适的话题（和标签不重复堆）
- [ ] 发布时间：生活/旅行类通常 11–13 点、19–22 点较好
- [ ] 评论区第一条自己占住（补充信息，不要写引导互动的话）

---

## 发完之后

- [ ] 半小时内看一眼有没有「不宜公开」「审核中」提示
- [ ] 如果被限流，去创作中心看具体违规提示，把原因补进
      `skills/xhs-guard/scripts/lexicon.json` 变成新规则
