# 安全改写对照表

改写的通用公式：

> **无法举证的宣称** → **可验证的个人事实**

不是把词藏起来，是把话说得站得住。次数、时间、具体感受都是可验证的；
「最」「100%」「必」不是。

---

## 一、绝对化用语

| ❌ | ✅ | 为什么这样改 |
|---|---|---|
| 最好吃的一家 | 我今年去了三次的一家 | 次数是事实 |
| 最好用的防晒 | 我回购到第三支的防晒 | 回购是事实 |
| 全网最低价 | 我比了四家，这家是我看到最低的（2026年8月） | 加了范围和时间 |
| 京都第一名的抹茶 | 我在京都喝过的抹茶里，我自己最喜欢这家 | 明确是主观 |
| 必去 | 如果你只有一天，我会先去这里 | 变成有条件的建议 |
| 必吃 | 我每次去都会点的 | 变成个人习惯 |
| 独一无二的体验 | 我没在别的地方见过这样的 | 限定在个人见闻 |
| 顶级景色 | 站在那儿我半天没说出话 | 用画面代替形容词 |
| 天花板级的氛围 | 那个光照进来的时候我手机都举不稳 | 同上 |
| 极致性价比 | 这个价格我觉得挺值，同价位我没找到更喜欢的 | 加主观限定 |
| 无人能及 | 我暂时没遇到能比的 | 限定在个人经验 |

**判断技巧**：把句子前面加上「我认为」，如果读起来变得奇怪或者站不住，
那就是绝对化宣称。「我认为这是最好吃的一家」→ 勉强；
「我认为我今年去了三次」→ 荒谬，说明它是事实不是观点。✅

## 二、承诺与保证

| ❌ | ✅ |
|---|---|
| 100% 出片 | 我拍了 40 张，有 6 张我挺喜欢 |
| 保证不踩雷 | 我这次运气不错，没遇到什么问题 |
| 一定会喜欢 | 我猜你会喜欢 |
| 绝对安全 | 我们全程走的正规路线 |
| 零风险 | 我提前做了这几件事来降低风险：… |
| 永久有效 | 我买的时候是这个规则，可能会变 |
| 无效退款 | （删掉，不要替商家做承诺） |

## 三、功效宣称

| ❌ | ✅ |
|---|---|
| 用了皮肤变白了 | 用了两周，我自己觉得暗沉没那么明显了 |
| 超级美白 | 我拍照的时候感觉气色好一点（也可能是灯） |
| 喝这个瘦了五斤 | 这段时间我在控制饮食也在走路，体重有变化，不确定是哪个起的作用 |
| 助眠神器 | 我睡前会用一下，心理上比较放松 |
| 修复屏障 | 我泛红的时候会用这个，自己感觉舒服一点 |
| 排毒祛湿 | （删掉。这是明确的功效宣称，没有安全版本） |
| 消炎杀菌 | （删掉。医疗功效，硬红线） |

**通用句式**：`我 + 时间 + 主观感受 + 不确定性`
「我用了两周，自己觉得好一点，但也可能是最近作息比较正常。」

不确定性不是弱点 —— 它既是合规的，也更像真人说话。

## 四、站外导流

| ❌ | ✅ |
|---|---|
| 想要地址的私我 | 店名在图三，直接搜就有 |
| 微信 xxx | （删掉。没有安全版本） |
| 主页简介有链接 | （删掉） |
| 抖音同名 | （删掉） |
| 需要清单的评论区扣 1 | 清单我直接写在图五了 |
| 加群一起拼 | （删掉） |

**原则**：把钩子换成直接给。
留钩子换互动是违规，直接给完反而更容易被收藏 —— 收藏是很强的推荐信号。

## 五、诱导互动

| ❌ | ✅ |
|---|---|
| 求点赞求关注 | （删掉） |
| 点赞+收藏，抽三位送 | （删掉整个机制） |
| 觉得有用的话记得三连 | 觉得有用可以收藏一下，出门再翻 |
| 关注我下次继续更 | 下次去别的地方我再来写 |
| 评论区告诉我你想看哪个 | 你要是也去过，我挺想知道你的感觉 |

**区别**：不索取、不交换、不设条件。
右列都是「我」的动作或邀请，左列都是要求「你」的动作。

## 六、旅行赛道专项

| ❌ | ✅ |
|---|---|
| 避雷这家 | 我遇到的情况是…，你们自己判断 |
| 黑店、宰客 | 结账时和菜单标价不一样，我拍了照 |
| 千万别去 | 我个人不会再去第二次，原因是… |
| 人均 380 | 2026 年 8 月我去的时候人均 380 左右，以店内为准 |
| 免签落地签 | 我出发前查的是免签，但政策会变，以官方最新公告为准 |
| 我们翻栏杆进去拍的 | （删掉。倡导危险/违规行为） |
| 野温泉超出片 | （删掉，或写成明确不推荐 + 说明后果） |
| 商家送了我们甜点 | （有对价 → 必须走蒲公英报备；或如实说明） |

**负面体验怎么写才安全**：
1. 只讲亲身遇到的**客观事实**（时间、金额、对话）
2. 不给**结论性定性**（不说「黑店」「骗子」）
3. 要点名就得有凭证；没凭证就别点名
4. 留一句「以上是我个人遇到的情况」

## 七、AI 感 / 通稿感（不违规，但压流量）

| ❌ | ✅ |
|---|---|
| 值得一提的是 | （直接删，说下一句） |
| 不仅仅是一次旅行，更是一场心灵的洗礼 | 就是去待了几天，回来觉得挺舒服 |
| 在这个快节奏的时代 | （删） |
| 综上所述 / 总而言之 | 反正 / 说白了 |
| 姐妹们冲 | （删） |
| 氛围感拉满 | 那个光打进来的时候特别好 |
| 绝了绝了 | （用具体细节代替） |
| 谁懂啊 | （删，或写成具体的事） |

**唯一判断标准**：这句话你会在微信里跟朋友说吗？
不会说就删掉。

## 八、改写时的红线

改写**不能**做的事：

- ❌ 拼音、谐音、拆字、插入空格或符号规避检测
- ❌ 为了合规把她的语气改成另一个人
- ❌ 编造事实来替换违规内容（把「商家送的」改成「我自己买的」= 造假）
- ❌ 删掉真实的负面体验（真实分享是被允许的，改的是定性词不是事实）
- ❌ 承诺「这样改就一定不会限流」—— 没人能保证

改写**应该**做的：

- ✅ 保留她的口头禅、标点习惯、句子长短节奏
- ✅ 每条都给具体替换句，不只说「建议修改」
- ✅ 说清为什么 —— 她要能自己判断下次怎么写
- ✅ 改完重扫一遍
