# xhs-script —— 视频脚本

## 先分清：写脚本 vs 改脚本

| 情况 | 怎么做 |
|---|---|
| **还没拍** | 写拍摄脚本 —— 目的是让她知道要拍什么，别漏镜头 |
| **已经拍了** | 写剪辑脚本 —— 从她手上的素材里排顺序，缺的用别的方式补 |
| **有草稿要改** | 走「改脚本」流程（见下），不要重写 |

**一定要先问清是哪种。** 给一个已经拍完的人写拍摄脚本，等于让她重拍。

---

## 第 0 步 · 读档案

```
读 profile/voice.md
```

口播稿就是她说的话，语气必须是她的。**书面语和口语不一样** ——
她写「反正，这样也挺好的」，说出来可能是「反正…就挺好的吧」。
口播稿要按**能顺出来**的标准写，不是按能读通的标准。

写完让她**大声念一遍**。念着别扭的地方就是要改的地方。

---

## 时长与节奏

小红书视频没有硬性时长限制，但生活/vlog 类的实际甜区：

| 时长 | 适合 | 结构 |
|---|---|---|
| **15–30 秒** | 单一瞬间、氛围片段 | 一个钩子 + 一个画面 + 一句话 |
| **45–90 秒** ★ | 大部分 vlog 片段 | 钩子 → 3–4 个场景 → 收尾 |
| **2–3 分钟** | 一天的记录、完整叙事 | 钩子 → 4–6 段 → 转折 → 收尾 |
| **3 分钟以上** | 慎用 | 完播率会明显掉 |

**前 3 秒定生死。** 完播率是最重要的推荐信号，而大部分人是在前 3 秒划走的。

## 分镜表格式

```markdown
# 脚本 · 京都下雨那天

时长目标：约 60 秒 ｜ 竖版 9:16 ｜ 语速约 5.5 字/秒

| # | 时间 | 画面 | 口播 / 字幕 | 音 | 备注 |
|---|---|---|---|---|---|
| 1 | 0:00–0:03 | 雨打在木窗上，特写，焦点在水珠 | （无口播，只有雨声） | 环境音：雨 | **钩子**。第一帧就要有雨 |
| 2 | 0:03–0:08 | 焙茶被放到窗台上，手入画 | 老板娘端来焙茶的时候 | 雨声 + 轻音乐淡入 | 手入画比空镜有人味 |
| 3 | 0:08–0:12 | 中景，我坐在窗边 | 说这种天最好不要出门 | 同上 | |
| 4 | 0:12–0:15 | 空镜：院子里的苔藓 | 我就真的没出门 | 雨声突出 | 这里留 1 秒静默 |
| 5 | 0:15–0:22 | 延时：光线变化 | 在窗边坐了一下午 | 音乐 | 延时素材要提前架好 |
| 6 | 0:22–0:26 | 茶杯空了，特写 | 反正，这样也挺好的 | 音乐淡出 | **收尾**，不要再加画面 |

## 口播

老板娘端来焙茶的时候
说这种天最好不要出门
我就真的没出门
在窗边坐了一下午
反正，这样也挺好的

## 拍摄清单

- [ ] 雨打木窗特写（要拍够 10 秒，剪的时候好选）
- [ ] 焙茶放到窗台，手入画（拍 3 遍不同速度）
- [ ] 中景我坐在窗边（三脚架，别手持）
- [ ] 院子苔藓空镜
- [ ] 延时：窗边光线变化（至少 20 分钟素材）
- [ ] 茶杯空了的特写
- [ ] **备用**：门口的伞、榻榻米纹理、雨伞上的水珠

## 待确认

- ⚠️ 延时那段有没有拍？没拍的话第 5 镜换成静止长镜
```

`## 口播` 这个小节名是约定的 —— `xhs-vlog` 靠它抽口播稿生成字幕：

```bash
python skills/xhs-vlog/scripts/make_srt.py drafts/<日期>-<slug>/script.md \
  --section 口播 -o drafts/<日期>-<slug>/subtitle.srt
```

## 钩子（前 3 秒）

**最有效的四种**，按适配生活/vlog 排序：

1. **直接给最好的画面** —— 不铺垫，把整条片子里最好看的一帧放在第 0 秒
2. **一句真实的对话** —— 「老板娘说这种天最好不要出门」
3. **一个反预期的状态** —— 人在旅行地但什么都没干
4. **一个未完成的动作** —— 手正要推开门（悬念）

**不要的钩子**：
- ❌ 「大家好我是…」（自我介绍是完播率杀手）
- ❌ 「今天带大家来到…」（旅游节目腔）
- ❌ 空镜 + 慢音乐开场（前 3 秒没信息）
- ❌ 「你绝对想不到…」（标题党，判违规）
- ❌ logo 动画片头（个人号不需要）

## 口播稿怎么写

| 原则 | 说明 |
|---|---|
| **按口语写** | 写完念一遍。念不顺就改 |
| **一句一个信息** | 别把两件事塞一句 |
| **短** | 单句 8–16 字。字幕一行放得下 |
| **留静默** | 不用每秒都说话。雨声、脚步声、静默本身是内容 |
| **不解释画面** | 画面有的别用嘴再说一遍（「这是一杯茶」） |
| **口语连接词** | 「然后」「反正」「就」—— 这些在书面语里是废词，在口播里是呼吸 |

## 改脚本

和 `xhs-polish` 同一个原则：**她的习惯是特征，不是错误。**

### ✅ 改
- 前 3 秒没钩子
- 镜头之间跳跃太大，看不懂
- 口播念不顺（书面语没转成口语）
- 单句太长，字幕放不下
- 时长超了，节奏拖
- 缺关键镜头（她拍不到的东西）
- 违规内容（危险行为、导流、绝对化）

### ❌ 不改
- 她的口头禅、停顿位置
- 她想留的静默
- 她的镜头审美（除非明显读不出信息）

改完给**逐镜对照**，不要只给一版新脚本。

## ⚠️ 视频类的合规重点

旅行 vlog 是 `xhs-guard` 里危险行为倡导条目的**高发区**。写脚本时就要避开，
不要等拍完了才发现不能发：

- ❌ 翻越栏杆、野温泉、野泳、爬屋顶、逃票、钻围栏
- ❌ 无人机在禁飞区起飞
- ❌ 投喂/触摸野生动物
- ❌ 野外用火
- ❌ 拍军事区、边防、机场跑道、铁轨上
- ❌ 他人正脸（尤其小孩）、车牌、门牌号
- ❌ 危险驾驶、闯红灯、逆行

**镜头也会被审核，不只是文字。**

口播稿和字幕写完后，一起扫一遍：

```bash
python skills/xhs-guard/scripts/xhs_scan.py drafts/<日期>-<slug>/script.md
```

## 落盘

```
drafts/<YYYY-MM-DD>-<短slug>/
├── script.md        # 分镜表 + ## 口播 + 拍摄清单
├── subtitle.srt     # 由 xhs-vlog 生成
├── note.md          # 视频笔记也要有标题/正文/标签
├── compliance.md
└── checklist.md
```

视频笔记同样需要标题、正文、标签 —— 走 `xhs-note`。
**别只给脚本忘了文案。**

## 交付时

1. 分镜表（完整表格）
2. 口播稿（单独一段，她要能直接照着念）
3. 拍摄清单（可勾选，她带着去现场）
4. 时长估算 + 节奏说明
5. 合规提醒（尤其危险行为那几条）
6. `⚠️待确认` 的部分
