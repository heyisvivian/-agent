# xhs-voice —— 建语气档案

「和我语气一样」这件事，不能靠让模型读几篇然后凭感觉模仿 —— 那样出来的是
模型对「小红书博主」的刻板印象（`✨氛围感拉满✨`、`姐妹们冲`、`值得一提的是`），
不是她。

所以要把语气**落成可校验的档案**：`profile/voice.md`。

---

## ★ 一个账号可能有多种语气

这是最容易做错的地方。

**同一个人写科普和写生活，很可能不是同一套写法。**
比如 emoji 的用法就可能完全不同：一种模式里当项目符号，另一种模式里
同样的密度就变成模板号了。

所以档案要**分模式**（register）。常见两种：

| 模式 | 内容 |
|---|---|
| **科普 / 信息型** | 法规解读、清单、干货、工具 |
| **生活 / 日常型** | vlog、旅行、心情、观察 |

**判定标准**：这篇是在讲**外部的事**（科普），还是讲**自己的经历**（生活）？

⚠️ **两个模式各自长什么样，只能从她的样本里读出来。**
不要套用「科普稿通常结论先行、生活稿通常第一人称」这类行业常识去填 ——
那是别人的写法，不是她的。没样本就留空。

可能有差异的维度（用来对比，不是用来填）：
人称 · 句长 · 标点习惯 · emoji 密度和用途 · 段落结构 · 开头结尾套路 ·
标题风格 · 篇长 · 给不给建议 · 带不带免责

不要假设只有一种模式。**先问用户她的账号有几种内容**，
以及**每种内容实际是怎么写的**（自己写 / AI 起草再改），再决定档案怎么建。

---

## 🛑 前置铁律：语料只能是她亲手写的

**AI 生成或 AI 起草的稿子不能当语料。**

拿 AI 稿去做「学我的语气」，等于让 agent 模仿另一个 AI。它写出来的更像通稿，
用户又把那些稿子当语料喂回来 —— **几轮之后账号的语气就是纯 AI 味，
而且是自己喂出来的。** 这是这个技能最容易毁掉整个账号的地方。

所以**建档前第一件事是问清来源**，不要看到 `samples/` 里有文件就开始统计：

> 这几篇是你自己敲的，还是 AI 写的 / AI 起草你改的？

| 情况 | 能当语料吗 |
|---|---|
| 她从头到尾自己写的 | ✅ 能 |
| 她写完自己改的 | ✅ 能 |
| AI 起草 + 她大改（面目全非） | ⚠️ 勉强，在档案里标注，权重放低 |
| AI 起草 + 她小改（顺一顺） | ❌ 不能 |
| 全部 AI 生成 | ❌ 不能 |

### 两种情况，两种做法

同一个账号里，不同类型的内容可能是不同工作方式产出的：

| 她怎么产出这类内容 | 档案怎么建 |
|---|---|
| **自己写** | **提取**（extract）—— 从样本统计出她的实际习惯，每条有原文作证 |
| **AI 起草她再改** | **定义**（define）—— 问她希望它读起来是什么样，写成给 agent 的规格 |

**这两件事不能混。** 对 AI 起草的内容做"语气提取"，提出来的是 AI 的语气。

「定义式」的问法不是「你的语气是什么」，而是：

- 你改 AI 稿的时候，最常删掉的是什么？
- 哪种句子你看到就想改？
- 你希望读者读完觉得你是个什么样的人？
- 有没有别的博主的科普稿你觉得"这个调子对"？（拿来对标，不是抄）

在档案里把这一节标清楚 `产出方式：AI 起草再改 · 定义式`，
这样后来的人（和后来的你）不会误以为那是统计出来的。

## 前置：拿到语料

语料放 `samples/`，一篇一个文件（`.md` 或 `.txt`）。
⚠️ **2026-08-21 起 `samples/` 进 git，仓库是公开的** —— 只放已发布的笔记，未发布的草稿不要放。

**多模式的话按子目录分**，这样能分别统计：

```
samples/
├── guide/     科普/信息型
└── life/      生活/日常/vlog/旅行
```

获取方式（agent 可以代读，但有边界 —— 见 `AGENTS.md` 1.5）：

- 小红书 App → 自己的笔记 → 长按复制正文，粘贴进文件
- 或者创作者后台的笔记管理页复制

**每种模式的篇数建议**：

| 篇数 | 效果 |
|---|---|
| 15+ | 统计稳定，档案能做得很准 ★ |
| 8–14 | 够用，但少数特征会不稳 |
| 3–7 | 只能抓大方向，要在档案里标「样本不足」 |
| 1–2 | 只能提取最鲜明的特征，其余**留空不要猜** |
| 0 | 走问卷，或标 `无样本` |

优先选**她自己满意的**笔记。硬着头皮写的恰饭稿、照模板套的攻略会**污染档案**。

## 步骤

### 第 0 步 · 确认来源

对着 `samples/` 里的每篇（或每个子目录）问一遍：**这是她自己写的吗？**

- 不确定就问，**不要假设**
- 是 AI 稿的挪出 `samples/`（比如放到 `samples/_ai/`，voice_stats 不会去读）
- 全部都是 AI 稿 → 走「定义式」，不要跑统计

### 第 1 步 · 分模式跑统计（拿数字，不拿印象）

```bash
python skills/xhs-voice/scripts/voice_stats.py samples/life
python skills/xhs-voice/scripts/voice_stats.py samples/guide
```

只有一个目录就直接 `samples`。

输出：篇数字数、句长分布、标点每百字频率、emoji 偏好与常用表、人称倾向、
口头禅候选（≥3 次的 n-gram）、每篇开头前 12 字、每篇结尾句、标题字数与样例。

`--json` 可拿结构化结果。

**分开跑是重点** —— 混在一起统计，两种模式的 emoji 密度会被平均成一个没意义的数。

### 第 2 步 · 读原文，解释数字

统计只告诉你「是什么」，不告诉你「为什么」。**必须再通读一遍原文**，回答：

- 她的**情绪落点**在哪？收在感慨、收在自嘲、收在一个具体动作、还是不收？
- 她**给不给建议**？
- 她怎么处理**负面情绪**？直说、绕开、还是用玩笑带过？
- 她的**细节密度**如何？「很好吃」还是「面汤上飘着一层油，我先喝了一口」？
- **标点和空格的小习惯**：半角还是全角逗号？数字两侧留不留空格？
  用不用破折号、`←`、`·`、`=`？这些最不容易被注意，但最能决定「像不像」。
- 她**从不做**什么？这个跟她做什么一样重要。
- **两种模式之间，哪些习惯是延续的？** 那些就是共同底线。

### 第 3 步 · 写 profile/voice.md

**结构见 `profile/voice.example.md`** —— 照那个骨架写：

```
为什么是双模式（如果只有一种就删掉）
模式判定表
─────────────
模式 A · 科普 / 信息型
  视角 / 句子 / 标点与排版细节 / emoji 的用法 / 结构 / 结尾 / 长度
模式 B · 生活 / 日常型
  同上
─────────────
共同底线
  确定的习惯
  绝对不是她（反例清单）
  待确认
```

三条硬规矩：

1. **每一条都要有原文引用作证**，不能空写形容词。
   「她比较克制」没用；「不用感叹号（0/1 篇）」有用。
2. **没样本的模式就留空，标 `无样本`，逐条列出「答不了的问题」。**
   ⚠️ 不要用另一个模式的特征去填，也不要凭常识猜 —— 猜错了后面每篇都跑偏。
3. **每一节都标可信度**（样本篇数）。1 篇样本的结论要写明是 1 篇。

### 第 4 步 · 让她验收

写完把档案给她看，问**具体**问题（不要问「准不准」）：

1. 「反例清单」里有没有你其实会用的？
2. 有没有你的习惯我完全没写到？
3. 「不用感叹号」这条对吗 —— 还是只是这几篇刚好没有？
4. 统计出来的标点/空格习惯（如果有），是刻意的还是输入法带的？
5. 生活稿里你希望自己「在场」（写我）还是「不在场」（写你）？
6. 这些样本都是你自己写的吗？有没有 AI 起草的混在里面？

按她的回答改，然后记一句 `已由用户 YYYY-MM-DD 确认`。

## 没有历史笔记怎么办

走 `references/questionnaire.md` 的问卷冷启动 ——
**她回答问卷时的语气本身就是语料。**

问完照样生成 `profile/voice.md`，但在顶部标：

```
可信度：低（问卷冷启动，无真实笔记样本）
→ 发过 5 篇之后，把它们放进 samples/ 重跑一次这个技能。
```

---

## 档案怎么用

- `xhs-note`（写）和 `xhs-polish`（改）**每次开工前都要先读它**，
  并且**先定模式**再动笔
- 写完**必须**拿「反例清单」自查一遍
- 用户说「这个不像我」时，不要只改这一篇 —— 问清哪里不像，把结论写回档案
- 她的风格会变。**每积累 10 篇新笔记就重跑一次**，看统计有没有漂移
- **出现第三种内容类型**（比如开始接商业合作、开始做测评）→ 加一个新模式，
  不要硬塞进现有的

---

## 两个原则

**档案里的「绝对不是她」比「她是什么」更有用。**
模型的默认输出就是小红书通稿腔，档案的主要作用是**把默认关掉**。

**样本不足时，留空比填满更有价值。**
一份标着「生活模式：无样本，以下 9 个问题答不了」的档案是诚实可用的；
一份把生活模式凭空编满的档案会让每一篇生活稿都错，而且错得很自信。
