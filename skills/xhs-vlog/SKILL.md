# xhs-vlog —— 剪辑协助

## 先说清能做什么、不能做什么

| ✅ 能做 | ❌ 不做（本版） |
|---|---|
| 素材清点与分类 | 自动切片、拼接、渲染 |
| 剪辑顺序与取舍决策 | 调色、降噪、稳定 |
| 卡点位置建议 | 自动去静音、去口癖 |
| **生成 .srt 字幕文件** | 生成剪映草稿工程 |
| 封面帧挑选建议 | 语音转写 |
| 导出参数 | 直接操作视频文件 |

用户明确要的是「脚本/分镜/剪辑清单 + 字幕文件」这一档。
**不要擅自加 FFmpeg 自动粗剪** —— 那是另一档，她没要。

如果她后来想要自动剪辑，可以问她要不要加 FFmpeg 那一层，但要先说清代价：
需要本地装 FFmpeg，且自动剪出来的东西通常还得手动收拾一遍。

## 一、素材清点

剪之前先知道手上有什么。让她按这个格式列（或者你看着文件名帮她列）：

```markdown
## 素材清点

| 文件 | 时长 | 内容 | 能用 | 备注 |
|---|---|---|---|---|
| IMG_0412.MOV | 0:24 | 雨打木窗特写 | ✅ | 前 8 秒最好，后面手抖 |
| IMG_0413.MOV | 1:12 | 焙茶入画 | ✅ | 拍了 3 遍，第 2 遍最自然 |
| IMG_0418.MOV | 0:41 | 我坐在窗边（中景） | ⚠️ | 有点过曝，能救 |
| IMG_0421.MOV | 3:20 | 延时：光线变化 | ✅ | |
| IMG_0425.MOV | 0:15 | 院子空镜 | ✅ | |
| IMG_0430.MOV | 0:08 | 街上的人 | ❌ | **有人正脸，不能用** |

可用总时长：约 6 分钟原始素材 → 目标成片 60 秒
```

清点时**顺手过一遍合规**：
- 有他人正脸（尤其小孩）→ 标 ❌ 或需要打码
- 有车牌、门牌号、店铺招牌上的电话 → 标注
- 有其他平台水印 → 换素材
- 有危险行为镜头（翻栏杆、野温泉）→ 标 ❌，别剪进去

## 二、剪辑顺序

拿 `script.md` 的分镜表对着素材排。**通常排不上** —— 现场总有变化。
这时候的工作是**在她实际拍到的东西里重新找结构**，不是让她补拍。

### 排序原则

1. **最好的画面放第 0 秒。** 不管它在时间线上原本是第几个。
   完播率比时间顺序重要得多。
2. **节奏：紧 → 松 → 紧。** 开头快切抓人，中段放慢让人喘，结尾给一个稳的收束。
3. **静默是内容。** 不用每一秒都填满口播和音乐。
4. **删。** 6 分钟素材剪 60 秒成片是正常的。舍不得删是新手最大的问题。
5. **一个片子只讲一件事。** 想讲两件事就做两条。

### 单镜时长参考

| 镜头类型 | 时长 |
|---|---|
| 钩子镜头 | 1.5–3 秒 |
| 特写/细节 | 1–2 秒 |
| 中景/人物 | 2–4 秒 |
| 空镜/氛围 | 2–3 秒 |
| 延时 | 3–5 秒 |
| 收尾镜头 | 3–5 秒（可以长一点，让人缓下来） |

**超过 5 秒的静止镜头要有很好的理由。**

## 三、卡点

生活/vlog 类**不需要硬卡点**。强行卡节奏会显得像模板。

需要卡的时候：
- 卡在**音乐的重音**，不是节拍上（重音才有力）
- 转场卡点每 4 或 8 拍一次，别每拍都卡
- 情绪转折处**留半拍空白**比卡上去更好

BGM 选择：
- 生活/旅行类选**低存在感**的（钢琴、氛围、lo-fi）
- 音量压到人声之下（口播 -6dB 左右，音乐 -18dB 左右，具体看耳朵）
- **一定要用平台曲库或有授权的音乐** —— 侵权音乐会被静音或限流

## 四、字幕（这是本技能的主要交付物）

### 从脚本生成

```bash
python skills/xhs-vlog/scripts/make_srt.py drafts/<日期>-<slug>/script.md \
  --section 口播 -o drafts/<日期>-<slug>/subtitle.srt
```

### 从口播稿文件生成

一行一句就行：

```bash
python skills/xhs-vlog/scripts/make_srt.py narration.txt -o subtitle.srt
```

### 已经知道时间码

行首写上，脚本照用：

```
00:00 老板娘端来焙茶的时候
00:04 说这种天最好不要出门
00:07.5-00:11 我就真的没出门
```

### 常用参数

| 参数 | 说明 |
|---|---|
| `--cps 5.5` | 每秒几个字。**语速慢就调到 4.5**，配完音发现字幕太快就降 |
| `--max-chars 16` | 单行最多几字，超了自动断句。竖屏建议 **12–16** |
| `--section 口播` | 只取 markdown 里这个小节 |
| `--offset 1.5` | 整体延后（片头有 1.5 秒空镜时用） |
| `--min` / `--max` | 单条最短/最长秒数，默认 1.2 / 6.0 |

### 导入剪映

> 剪映 → 导入 → **字幕 → 本地字幕** → 选这个 `.srt`

导进去是排好的字幕轨，比一句一句敲快得多。样式（字体、描边、位置）在剪映里统一调。

### 字幕规范

- 单行 **12–16 字**，竖屏放不下更多
- 位置：**下方，但要避开小红书 UI** —— 底部留出约 15% 安全区
- 描边或半透明底：白字在浅色画面上会消失
- **口播和字幕要一致。** 不一致读者会分心
- 字幕里的字**一样会被审核** —— 生成后扫一遍：

```bash
python skills/xhs-guard/scripts/xhs_scan.py drafts/<日期>-<slug>/subtitle.srt
```

## 五、封面帧

视频笔记的封面**决定点击率**，不要用系统默认的第一帧。

### 两条路

**A · 从视频里选一帧**（最真实，点击率最好）
挑帧标准：
- 主体清楚，构图干净
- **有人出镜的帧点击率平均高 30–50%**
- 有留白能放标题（上部或下部要有相对干净的区域）
- 不要动态模糊的帧

选好后在剪映里导出这一帧，然后压字：

```bash
python skills/xhs-cover/scripts/render_cover.py \
  --title "京都下雨那天|我什么都没干" \
  --bg frame.png --style photo \
  --out drafts/<日期>-<slug>/cover.png
```

**B · 单独做封面** —— 走 `xhs-cover` 的路线 A 或 C。

⚠️ 小红书视频封面**仍然按 3:4 出**（1080×1440），不是 9:16。
视频本身是 9:16，封面是 3:4，这两个不一样。

## 六、导出设置

| 项 | 值 |
|---|---|
| 分辨率 | **1080×1920**（9:16 竖版） |
| 帧率 | 与拍摄一致（通常 30fps；拍 60 就导 60） |
| 码率 | 剪映选「高质量」；手动的话 12–20 Mbps |
| 格式 | MP4 (H.264) |
| 音频 | AAC 48kHz |

### ⚠️ 导出前必查

- [ ] **关掉剪映片尾**（导出设置里取消「添加片尾」）
- [ ] **没有任何平台水印** —— 抖音/快手/B站 logo 或 ID
      → 这条判搬运，是最确定的限流原因之一
- [ ] 素材里没有他人正脸/车牌/门牌号，或已打码
- [ ] BGM 有授权
- [ ] 首帧不是黑场

## 七、发布

视频笔记同样需要标题、正文、标签 —— 走 `xhs-note`，**别只给视频忘了文案**。

⚠️ **AI 声明**：如果封面用了 `image_gen`，或视频里有 AI 生成的画面，
发布时【设置】→【内容类型声明】→ 勾选【笔记含 AI 合成内容】。
